## Theme catalog

### Desktop-inspired

- [Big Sur GRUB Theme](https://raw.githubusercontent.com/mehedi-codes/awesome-grub/main/BigSur-grub-theme.png) - macOS-inspired look with a polished glassy aesthetic.
- [Matter GRUB Theme](https://raw.githubusercontent.com/mehedi-codes/awesome-grub/main/matter-grub-theme.gif) - Smooth, colorful, and contemporary GRUB styling.
- [Sleek GRUB Theme](https://raw.githubusercontent.com/mehedi-codes/awesome-grub/main/Sleek-grub-theme.gif) - Minimal and streamlined appearance.
- [Gentoo GRUB Theme](https://raw.githubusercontent.com/mehedi-codes/awesome-grub/main/gentoo-grub-theme.png) - Linux distro-inspired design with classic styling.

### Dark and cinematic

- [Cyberpunk 2077 GRUB Theme](https://raw.githubusercontent.com/mehedi-codes/awesome-grub/main/Cyberpunk-2077-grub-theme.png) - Neon sci-fi styling for a dramatic boot menu.
- [CyberRE GRUB Theme](https://raw.githubusercontent.com/mehedi-codes/awesome-grub/main/CyberRE-grub-theme.png) - Dark, high-contrast cyber aesthetic.
- [Matrix GRUB Theme](https://raw.githubusercontent.com/mehedi-codes/awesome-grub/main/Matrix-grub-theme.jpg) - Green-on-black matrix-inspired boot screen.

### Retro and game-inspired

- [GRUB Fallout Theme](https://raw.githubusercontent.com/mehedi-codes/awesome-grub/main/Grub-Fallout-Theme.jpg) - Retro, post-apocalyptic, and gritty.
- [Sekiro GRUB Theme](https://raw.githubusercontent.com/mehedi-codes/awesome-grub/main/sekiro_grub_theme.png) - Game-inspired design with strong action aesthetics.

### Full collections

- [Modern Grub2 Themes](https://github.com/mehedi-codes/awesome-grub/blob/main/Modern_Grub2_Themes/README.md) - A directory of curated modern GRUB theme variants and previews.

## Contributing

Contributions are welcome.

If you want to add a new theme, improve documentation, or share a screenshot, please open a pull request or submit an issue.

Suggested additions include:

- new GRUB theme references
- better theme categorization
- extra screenshots or previews
- documentation improvements

## Related resources

- [GRUB](https://www.gnu.org/software/grub/) - The GNU GRUB bootloader.
- [grub2-themes](https://github.com/vinceliuice/grub2-themes#readme) - A large collection of modern GRUB themes.
- [Catppuccin GRUB](https://github.com/catppuccin/grub#readme) - Pastel GRUB themes inspired by Catppuccin.
- [0xMRTT / GRUB-Themes](https://github.com/0xMRTT/GRUB-Themes) - Another community resource for GRUB theme ideas.
